## ¿Quién soy?

Soy alguien al que le gusta **crear cosas, experimentar y descubrir cómo funcionan**.

No siempre comienzo sabiendo exactamente qué hacer.

Muchas veces todo empieza con una pregunta:

> **"¿Y si pudiera hacer esto?"**

Después viene investigar, probar, equivocarme, arreglar y volver a intentar.

Y cuando finalmente funciona...

> **"¿Y si ahora le agregamos esto?"**

Ese ciclo probablemente nunca termine.

<img src="https://capsule-render.vercel.app/api?type=rounded&color=0:020617,35:0B4F71,70:2563EB,100:60A5FA&height=120&section=header&text=FLUXIONICS&fontSize=45&fontColor=FFFFFF&animation=fadeIn" width="75%">

<table>
<tr>
<td>

### Simulación · Aprendizaje · Tecnología

**Fluxionics** es uno de los proyectos que representa mejor mi forma de trabajar.

La idea es construir una experiencia tecnológica donde diferentes herramientas, sistemas de aprendizaje y experimentos puedan convivir.

Entre las cosas que forman parte de este universo:

* Simulación de circuitos.
* Calculadoras y herramientas.
* Tutoriales.
* Ejemplos interactivos.
* Sistemas educativos.
* Interfaces dinámicas.
* Experimentos tecnológicos.
* Nuevas ideas que siguen apareciendo.

No quiero que sea solamente un proyecto.

Quiero que sea **un universo que pueda seguir creciendo**.

</td>
</tr>
</table>
