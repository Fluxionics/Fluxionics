## Mi forma de trabajar

<details>
<summary><b>01 · Tengo una idea</b></summary>

<br>

Primero digo:

**"Esto estaría fácil."**

Después abro el editor.

Después descubro que no estaba fácil.

Después sigo.

</details>

<details>
<summary><b>02 · Algo no funciona</b></summary>

<br>

Mi proceso científico:

```text
¿Funciona?
   │
   ├── Sí ──► No tocar nada.
   │
   └── No ──► Revisar.
                │
                ▼
             Buscar.
                │
                ▼
          Probar algo.
                │
                ▼
          Romper otra cosa.
                │
                ▼
             Arreglar.
```

</details>

