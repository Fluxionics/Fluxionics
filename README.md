## Hola, soy Fluxionics

Me gusta **crear, experimentar y aprender haciendo**.

No tengo todo perfectamente planeado. Muchas veces aparece una idea, investigo cómo hacerla y termino aprendiendo un montón en el proceso.

Para mí, la tecnología es: **curiosidad + creatividad + prueba y error**.
